1. この拡張機能について

Business Report Bridge for Docs(以下「本拡張機能」)は、利用者が Gmail から送信した「業務報告」メールの本文を、利用者が指定した Google ドキュメントへ転記するための Chrome 拡張機能です。

2. 取得・利用する情報と目的

情報利用目的
Gmail の送信済みメール(件名に「業務報告」を含むもの)の件名・宛先・本文転記対象の判定と、ドキュメントへ転記する内容の作成
Google ドキュメントの内容(タブ構成・日付の見出し)転記先の位置の判定と、報告の追記
Google ドライブのフォルダ情報(利用者が指定したフォルダID)転記先ドキュメントの確認
利用者が設定したマッピング(宛先メールアドレス、医院名などの表示名、ドキュメントID、フォルダID、タブ名)と共通設定宛先ごとの転記先の振り分け
処理済みメールのIDと処理ログ二重転記の防止、画面への結果表示
利用者の Google アカウントのメールアドレス接続中のアカウントの表示

Gmail 画面上では、「メッセージを送信しました」の表示や送信ボタンの操作を検知して、確認処理を早めるためだけの小さなスクリプトが動きます。このスクリプトはメールの内容を読み取りません。

3. 情報の保管と送信

  • マッピングと共通設定は Chrome の同期ストレージ、処理ログと処理済みメールIDは端末内のストレージに保存します。同期ストレージは、利用者自身の Google アカウントを通じて、利用者の Chrome 間で同期される場合があります。
  • 本拡張機能は提供者のサーバーを持たず、情報を提供者や第三者のサーバーへ送信しません。通信先は Google の公式API(Gmail API・Google Docs API・Google Drive API)のみです。
  • 広告、アクセス解析、トラッキングは行いません。
  • 情報を販売、貸与、第三者へ提供しません。提供者が利用者の情報を閲覧することもありません。
  • 取得した Google ユーザーデータは、本拡張機能の機能提供のみに使用します。広告への利用や、AI モデルの学習には使用しません。本拡張機能による Google API から受け取った情報の利用と他アプリへの移転は、Limited Use の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

4. 利用する権限

  • gmail.readonly: 送信済みの業務報告メールを読み取るため。メールの送信・削除・変更はしません。
  • documents: 転記先ドキュメントへ追記するため。
  • drive.readonly: 指定フォルダ内のドキュメント情報を確認するため。
  • identity / identity.email: Google アカウントへの接続と、接続中アカウントの表示のため。
  • storage: 設定と処理ログを保存するため。
  • alarms: 一定間隔(既定 約5分)で新しい送信メールを確認するため。
  • notifications: 転記の成功・失敗を通知するため。
  • Gmail(mail.google.com)と Google の API への通信: 上記の処理のため。

5. 個人情報を含む可能性のある内容の取り扱い

業務報告の本文に個人情報が含まれる場合があります。本拡張機能は本文を Google の API の間でのみ受け渡し、外部へ保存・送信しません。メールに含める内容の判断は、利用者(および所属組織の規程)の責任で行ってください。

6. データの削除

  • 拡張機能の画面から、登録したマッピングを個別に削除できます。
  • 拡張機能を削除すると、ブラウザに保存された設定と処理ログも削除されます。
  • Google アカウントとの接続は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも解除できます。

7. 変更

本ポリシーを変更する場合は、このページを更新し、最終更新日を改めます。
